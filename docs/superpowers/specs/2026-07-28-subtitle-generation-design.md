# 本地视频字幕生成接入设计

## 目标

在不修改 `D:\software\software_for_chickenrice` 模型发行目录、不修改现有批处理文件、不调用 ffmpeg 的前提下，将模型字幕生成能力接入 VidNorm 主界面。

## 方案

主界面使用本次本地扫描得到的真实视频路径，后台通过 `infer.exe` 子进程生成字幕。调用进程的工作目录固定为模型根目录，以满足模型程序对 `models`、VAD 文件和 `generation_config.json5` 的相对路径要求。

不模拟拖拽批处理文件，因为批处理末尾的 `pause` 会阻塞后台任务。系统直接使用与 GPU 视频批处理一致的参数：视频扩展名、`srt,vtt,lrc` 输出格式和 `cuda` 设备。

## 数据流

```text
本地扫描结果 -> 生成字幕任务 -> 后台调用 infer.exe -> 检查字幕文件 -> 返回逐文件结果
```

当前阶段不写入数据库、不移动或覆盖视频、不执行 ffmpeg 封装。字幕文件直接生成到各视频所在目录，模型自身负责跳过已有字幕；系统通过 `--overwrite` 配置控制覆盖行为。

## 失败与验证

- 模型目录、`infer.exe` 或视频路径不存在时立即返回参数错误。
- 模型进程非零退出时任务失败，并保留模型输出日志。
- 模型进程退出码为零但未生成目标字幕时任务失败，避免误报成功。
- 单个文件失败不影响同批其他文件，接口返回逐文件状态和汇总数量。

## 配置

通过 `.env` 支持以下配置，并为当前模型目录提供默认值：

- `TRANSLATION_MODEL_ROOT`
- `TRANSLATION_INFER_EXE`
- `TRANSLATION_DEVICE`
- `TRANSLATION_SUB_FORMATS`
- `TRANSLATION_OVERWRITE`

## 界面

主界面在已经完成扫描且存在视频时显示“生成字幕”操作。操作进入现有 GUI 任务队列，完成后提示成功和失败数量；调用期间不阻塞界面。
